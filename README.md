# Checklist Web

O Checklist Web é uma ferramenta muito usada na entrada e organização de pessoas convidadas para o evento. Este modelo é gratuito, sem limite de quantidade de pessoas (nomes), sem cobranças adicionais futuras.

## Como funciona?

- Acesse o link disponível neste repositório e abre em seu navegador
- Você terá a possibilidade de importar nomes manualmente (digitando nome por nome por linha) ou importar arquivos prontos com extensões como .xlsx, .txt, .csv
- O sistema conta com uma trava de segurança para evitar a edição da lista por engano ou por um simples esbarrar na tela
- O usuário pode exportar a lista de convidados já pronta no Checklist Web para compartilhar com outras pessoas, sendo compartilhado o arquivo com extensão .csv
- Você poderá testar o Checklist Web com uma lista pré-definida
- A lista ordena automaticamente os nomes na ordem alfabética, ou seja, A-Z
- Para apagar a lista do Checklist Web, é necessário fazer um pequeno passo de segurança escrevendo "Apagar" no campo indicado
- Há a possibilidade de adicionar mais pessoas mesmo após importar ou ter editado a lista anteriormente
- O sistema não possui sincronização com outros usuários do mesmo projeto, sendo individual, pela ausência de um banco de dados

## Link para acesso

O Checklist Web funciona para sistema Android e IOS, sendo aberto inteiramente no navegador do usuário, sem dependências externas como banco de dados.
